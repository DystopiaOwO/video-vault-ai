# Checkpoints

## Before Planning

- 素材已匯入專案資料夾。
- 內容感知已完成或明確允許使用 mock provider。
- frame summary、tags、segments 已寫入 index。

## Before Review

- `project_plan.json` 已產生。
- `project_script.md` 已產生。
- BGM recommendations 已產生。
- title cards 僅用於場景/地點切換。

## Before Formal Output

- `review_status.json.approved_by_user == true`
- `project.status == approved`
- `project_plan.json.status == approved`
- 未處理的 revision notes 已確認可接受。

## After Output

- 輸出檔存在。
- YouTube 署名資訊已保留。
- 使用的 BGM 來源與授權可追溯。
