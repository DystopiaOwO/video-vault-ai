# Issue #36 — AI perception and user story context

## Ownership model

Frame-level AI perception and project-local user context are separate data owners:

- `frames.vision_summary` is generated by perception runs and is read-only to the clip-summary editor.
- `project_videos.user_summary` is written by the user for one project-media relation.
- `videos.user_summary` is only a pre-project default for unowned inbox media; creating a project snapshots it into the project relation.
- `summary_override` remains a legacy migration source and must not receive new editor writes.

Saving or clearing user context must never update a frame row. Reanalysis may replace AI observations but must preserve project-local user context.

## API contract

A project clip exposes four distinct values:

- `ai_visual_summary`: representative AI frame observations;
- `user_summary`: editable project-local guidance;
- `effective_summary`: user guidance when present, otherwise AI observations;
- `effective_summary_source`: `user`, `ai`, or `none`.

`visual_summary` remains a compatibility alias for `ai_visual_summary`; it is no longer the editable field.

## Story planning

Saving a user summary rebuilds the project plan and invalidates prior approval. Recognized positive guidance can override tag-derived grouping. Explicit negative guidance can veto a group.

For example, `這段是抵達飯店，不要放在早餐` should group the clip under `抵達／住宿`, record `飲食` as avoided, and preserve the decision provenance in both `project_plan.json` and `project_script.md`.

## Legacy migration

Old databases may contain values in `project_videos.summary_override`:

- When the value differs from the first AI frame observation, it is conservatively migrated as user context.
- When all non-empty frame summaries are identical to the legacy value, ownership is ambiguous and the relation is flagged `review`.
- When multiple AI observations exist and the legacy value matches the first observation, it remains classified as a legacy AI snapshot.

The migration never rewrites frame perception rows.
