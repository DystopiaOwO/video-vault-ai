# Video Vault AI 互動 UI 原型 V2

這份原型用來確認資訊架構、操作密度與響應式版面，不會呼叫正式 API，也不會修改專案資料。

## 啟動

```powershell
cd web
npm ci
npm run dev
```

開啟：

```text
http://127.0.0.1:5173/ui-prototype-v2.html
```

## 可操作內容

- 側邊導覽與工作流程步驟可切換工作區。
- 分鏡清單一次只選取一個片段，右側 Inspector 會同步更新。
- Inspector 可測試起點、終點、故事角色、備註、納入與鎖定狀態。
- 納入／排除會同步更新分鏡列、儀表板片段數與輸出摘要。
- 調色預覽可切換 Before、After 與片段預覽。
- 調色／音訊設定使用同一個右側面板並以頁籤切換。
- 核准頁必須先完成兩項人工確認，才能核准並解鎖正式輸出按鈕。
- 所有儲存、核准與輸出動作只顯示原型 Toast，不會送出請求。

## 測試

```powershell
npm test -- ui-prototype-v2.test.ts
```

測試涵蓋：

- 不包含假儲存空間、升級方案與無功能搜尋框。
- 工作區切換。
- 選取片段後更新 Inspector。
- 納入／排除同步更新總數。
- Approval Gate 與正式輸出鎖定。
- 1180、900、680、430px 響應式規則存在。

## 人工驗收尺寸

瀏覽器 DevTools 建議依序檢查：

- 1440 × 900：完整桌面版，分鏡 List + Inspector。
- 1180 × 820：Inspector 移到主內容下方。
- 900 × 768：窄版側邊導覽。
- 680 × 900：頂部行動導覽。
- 430 × 860：手機單欄。

## 此階段不包含

- 正式 React 元件拆分。
- 後端 API 串接。
- 實際影片縮圖與播放器。
- 拖曳排序資料更新。
- 正式 Render Job 建立。

原型通過人工確認後，再將結構搬入 React 工作區，避免直接在正式頁面反覆修改資訊架構。
